#+title: ThinkPad T480s NixOS
#+startup: overview

* Purpose
This is the standalone NixOS configuration for the Lenovo ThinkPad T480s.  It
translates the working T430 workflow into NixOS while keeping T480s hardware
facts host-owned.  The intended desktop remains X11, DWM, dmenu and slstatus,
with Brave, Emacs, Ghostty, tmux, Fish and Yazi as the approved application
roles.

This repository does not import another machine's repository.  Earlier source
was mechanically useful; the retained active source is now assigned to a
T480s-owned =config/=, =core/= or =host/= boundary.

The import direction is =flake -> host -> core=.  Core never imports host.
Nix and Home Manager own packages, generated configuration and live links.

Home Manager module because no separate live configuration is required.  DWM,
dmenu and slstatus headers are compile-time exceptions.
