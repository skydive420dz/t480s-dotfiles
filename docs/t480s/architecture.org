This is the active ownership graph.  Volatile build, activation, profile,
booted-generation and runtime results belong in [[file:handoff.org][the handoff]]
and [[file:gates.org][the gate ledger]], not in this architecture map.

The security-sensitive access block remains inline in the host root.  Moving
it is structural only, but requires a separate exact review because it contains
SSH keys and the existing restricted passwordless reboot/poweroff rules.

* Flake Boundary
The flake composes only =nixosConfigurations.t480s=.  It selects the concrete
T480s system and Home Manager roots and supplies the repository path used by
approved live links.  It does not import an MSI host, MSI defaults, MSI Secure
Boot policy or another repository.

The T480s host may import =core=.  Core may not import =host=.  Application
configuration never imports Nix; modules only package or link it.

* Behavior Ownership
| Behavior | Provider |
|----------+----------|
| X server and startx session | T480s system X11 module |
| Window management and exact tag/layout/key policy | overridden =pkgs.dwm= plus =config/dwm/dwm.h= |
| Launcher | overridden =pkgs.dmenu= plus =config/dmenu/dmenu.h= |
| Bar status | overridden =pkgs.slstatus= plus =config/slstatus/slstatus.h= |
| Wallpaper, repeat rate and Xresources | T480s X11 module plus live =config/x11/= and =config/wallpaper/= sources |
| Caps to Escape and natural scrolling | XKB and libinput |
| Browser | Brave Home package and T480s-owned managed policy |
| Editor | live =config/emacs/= plus explicitly selected external tools |
| Terminal and multiplexer | Ghostty and tmux with live application configuration |
| Shell and tty1 X startup | Fish with live configuration |
| File/image workflow | Ranger live configuration, nsxiv and lean mpv |
| Audio | PipeWire, WirePlumber, ALSA compatibility |
| Bluetooth media | BlueZ and enable-only ownership of its native user =mpris-proxy= unit |
| Networking and remote access | NetworkManager and OpenSSH |
| Charge thresholds and AC/battery policy | TLP |
| Fingerprint and sudo authentication | T480s fingerprint module, =open-fprintd=, =python-validity= and sudo-only PAM |
| Lid and sleep keys | systemd-logind |
| Critical battery | UPower, initially =PowerOff= |
| Trim | weekly fstrim timer |

* Application Substitutions
| T430 role | T480s owner |
|-----------+-------------|
| Firefox | Brave |
| Neovim | the clean Emacs configuration adapted and owned in this repository |
| =st= | Ghostty |
| OpenRC/ACPI/cron ownership | NixOS modules and systemd |

The saved DWM configuration is retained except for the explicit Ghostty and
=brightnessctl= substitutions.  =brightnessctl= replaces =xbacklight= because
it owns the real kernel backlight interface on this machine.

* Deferred Architecture
- No XLibre overlay until the supported Xorg baseline passes.
- No custom/ThinLTO kernel until runtime measurements justify it.
- No backup timer until an independent destination is identified.
- No hibernate critical action until controlled resume acceptance passes.
- No language stack merely because the Emacs config contains optional support.
- Fingerprint authentication is accepted for sudo only with password fallback;
  login and other PAM surfaces remain disabled.  Browser passkeys remain
  deferred pending a mature Linux platform-authenticator design.
- Dormant modules remain candidates, not active architecture.
