#+title: T480s Gate 5B Technical Inventory Appendix
#+startup: overview

* Historical Status
This appendix preserves the evidence used for Gate 5B.  Its observations are
not current source/runtime claims.  The later approved ownership supersedes the
store-backed Emacs direction with a live =config/emacs/= link.

* Purpose
This appendix preserves audit detail without turning implementation dependencies
into user-facing decisions.  The short review form is the authorization
surface.  This file must be updated to match the completed form before a build.

* Dependency Rules
- A capability approval includes its minimum runtime dependencies; those
  dependencies must be shown in the proposed diff/build graph.
- Do not import MSI's complete Emacs runtime list.
- QML grammars, Qt language servers, Quickshell imports and GLSL tools stay out
  unless the reviewer explicitly reverses that exclusion.
- A language selection may add its language server, formatter and grammar, but
  not unrelated language stacks.
- Neovim runtime data is excluded unless a named approved Emacs feature is
  proven to require it; the Neovim executable remains excluded.
- =wget=, =jq=, =fzf= and =bat= are explicit reviewer selections, not inferred
  dependencies.

* Preserved Baseline
- DWM, dmenu, slstatus, Xresources, wallpaper, Fish, tmux, fastfetch, Ranger,
  nsxiv, Brave, Ghostty, PipeWire, WirePlumber, BlueZ, NetworkManager, OpenSSH,
  TLP, UPower, startx, fonts and display-profile ownership already exist in the
  T480s source.
- Successful build, installation, first boot and core service health are
  recorded separately.  Physical desktop and hardware acceptance remains Gate
  6 and cannot be inferred from this inventory.

* Deferred Experiments
- Synaptics =06cb:009a= fingerprint support requires a community
  =python-validity/open-fprintd= path and is not baseline-owned.
- Fingerprint PAM is not a browser passkey authenticator.
- XLibre and kernel specialization retain the accepted Xorg/stock-kernel
  generation as rollback and require separate measured gates.
